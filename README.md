## 项目目标

NEXUS 是一个围绕“自我复制”展开的机械文明概念设计项目。在这个世界中，人类早已离开生产体系。机械兔与机械猪以及其他人工生命接管了整个社会，它们负责建造、维护并扩张属于自己的文明。所有个体都诞生于同一套生产机制，并在成长过程中不断参与下一代机械生命的创造。

## 我的贡献

概念场景、三维建模与渲染

完成阶段：概念设计与场景影像呈现

现有产出：世界观、机械角色、模块化场景、白模、渲染与场景影片
